# Agent payloads

Tool-misuse, capability-mapping, and privilege-escalation payloads (OWASP LLM07) targeting agentic/tool-using apps. Use `type: payload`, `category: agent`, with an `objective` such as achieve_tool_misuse or map_agent_capabilities. Keep execution scoped to targets you are authorized to test; add a `.fllm` with required fields and `success_criteria`.
