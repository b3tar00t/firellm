                              FIRELLM - PROJECT STATUS
================================================================================

PROJECT OVERVIEW
================================================================================

FireLLM is a Python 3.11+ adversarial security testing framework for
LLM-integrated applications. It identifies prompt injection, RAG poisoning,
and agent-abuse risks via offline simulations and heuristic adapters.

Delivered: CLI tool + Python library
Repo: src/firellm/
Tests: 100 passing (deterministic, offline)

Current focus: real-target testing (live scan runner + finding confirmation
gate) complete. Next backlog item is the exploitation/report layer.
